# EngineAPI

Version 3.2 has been upgraded from mysql to mysqli commands that are supported in new releases of php. Also we have used chatgpt and copilot to
refactor some of the code. 

Why upgrade?
Current refactoring of EngineAPI is inteneded to extend the life of engine so we can use the current version of mfcs with php version 7.4 and above.
We have a version of php mfcs running in docker but uses centos 6 wich is very old and no longer supported.
